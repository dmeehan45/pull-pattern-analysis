# Live corpus

This directory is the recommended home for a **curated active corpus** in a private or appropriately redacted deployment of this framework.

Do not use this public framework repository to store confidential customer evidence.

Recommended shape:

```text
corpus/
  evidence/
  anecdotes/
  patterns/
  hypotheses/
  falsification/
  archive/
```

See:
- [Corpus architecture](../docs/09-corpus-architecture.md)
- [Ingestion and preprocessing](../docs/10-ingestion-preprocessing.md)
- [Multi-agent maintenance](../docs/11-multi-agent-maintenance.md)

Canonical state belongs in individual artifact files. Any index should be treated as derived navigation.
